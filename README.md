# Breathe Buddy: AI in Breathwork Facilitation

## Academic Context
This project was developed for **Great Bay Community College** as an undergraduate inquiry into the intersection of technology and Breathwork. It serves as the final technical component of a thesis project exploring how artificial intelligence can support, but not replace, human intuition in breathwork practices.

## Prototype Status & Known Limitations

Please note that **Breathe Buddy** is currently a proof-of-concept prototype developed for academic research. 

* **Experimental Nature:** As a prototype, this application may contain technical bugs or inconsistent AI behaviors. 
* **Prototype Purpose:** It is intended to demonstrate a design architecture and research findings rather than serve as a production-ready tool.
* **Continuous Improvement:**
  > [!CAUTION]
  > The project is a living example of how AI can be integrated into breathwork practices, and it is not yet optimized for all edge cases and is not to be used as a substitute for medical purposes or advice.

## The Mission
Breathe Buddy is an interactive web application designed to explore the boundaries of digital healing tools. The primary goal was to create a functional bridge between modern data science and ancient somatic breathing practices. By utilizing a Next.js and Tailwind CSS architecture, the project demonstrates how AI can be a powerful logistical ally for practitioners while maintaining a clear boundary around the necessity of human emotional attunement.

## The Facilitator Robot
The "Breathe Buddy" robot is the visual of this prototype. It is designed to represent a supportive, non-judgmental presence that guides users through the mechanics of regulation. 

In this prototype, the robot represents:
* **Logistical Support:** Handling symptom analysis, timing, and countdowns so the user can focus entirely on their breath.
* **Accessibility:** Providing a friendly, approachable entry point for somatic work, which is especially beneficial for children and beginners.
* **The Boundary of AI:** The robot is a deliberate example of AI's capability to mimic empathy and patterns without possessing true emotional intelligence. It serves as a reminder that while a machine can guide a rhythm, it cannot "hold space" for the deep subconscious journeys or trauma breakthroughs that require a human facilitator.

## Core Features
* **Interactive AI Facilitator:** A conversational interface that manages breathing steps and provides technique recommendations based on user sentiment.
* **Animated Robot Visual:** A custom character that expands and contracts in sync with the user's breathing rhythm to provide visual guidance.
* **Sentiment Analysis:** Logic that processes user reflections before and after exercises to determine if a session should be deepened or adjusted.
* **Academic Integration:** A dedicated section featuring research findings, video examples of somatic benefits in children, and a critical analysis of AI's performance in academic writing.

## Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS with a custom Glassmorphism design system
* **Animations:** Framer Motion for smooth transitions and the breathing visualizer
**AI Assistance:** Google Gemini (Code Collaboration for creating of the AI Breathe Buddy and some animated elements)
* **Icons:** Lucide React
* **Deployment:** Vercel

## Research Findings
During the development of this project at Great Bay Community College, several observations were made regarding AI's role in the field:
1. **Source Reliability:** AI often lacks the substance needed for high level academic research and may provide incorrect data from abstracts.
2. **Somatic Limitations:** A machine cannot feel bodily sensations, making it a tool for regulation rather than a substitute for a human facilitator during emotional breakthroughs.
3. **Productivity Utility:** AI remains a powerful tool for cutting down research time and assisting with logistical tasks despite its current limitations.
